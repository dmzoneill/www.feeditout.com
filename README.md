# feeditout.com

A version of the Feed It Out site.

## Contents

- `auth`: registration, login and logout.
- `books`: an ebook search that can email a book as an attachment.
- `photos`, `texts` and `serials`: content sections.
- `proxy`: a web proxy.

## Tech

- PHP and MySQL
- JavaScript

This is an archive of an old site, kept for reference.
